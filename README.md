# To-Do app

Tracks tasks and goals you have.

**Live URL:** https://todo-web-x8ks.onrender.com/

## Run it locally

1. `pip install -r requirements.txt`
2. `python todo.py`
3. Open http://127.0.0.1:5000 — add `/add` to the URL to add a task.

## Tech

Flask and SQLite. Tasks persist in SQLite, so they survive server restarts.
